# Color Palette Generator

Ett litet fritidsprojekt skapat för att öva på webbutveckling och ha kul med färger. Sidan genererar en palett med fem slumpmässiga färger och visar deras HEX-koder.

## Funktioner

- Skapar en ny palett automatiskt när sidan öppnas.
- Genererar en ny uppsättning med fem färger via knappen **Generate Palette**.
- Kopierar en färgkod till urklipp när du klickar på färgrutan eller kopieringsikonen.
- Anpassar palettens layout för olika skärmstorlekar.

## Kom igång

Öppna `index.html` i en webbläsare. Ingen installation eller byggprocess behövs.

Google Fonts och Font Awesome laddas från externa CDN:er. Kopiering till urklipp använder webbläsarens Clipboard API.

## Teknik

Projektet är byggt med vanlig HTML, CSS och JavaScript, utan ramverk.
